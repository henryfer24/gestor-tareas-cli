# Gestor de Tareas CLI

Aplicación de consola desarrollada en Python para administrar una lista de tareas
desde la terminal.

## Descripción

El Gestor de Tareas CLI permite agregar, listar, completar y eliminar tareas
mediante un menú interactivo en consola. El proyecto se desarrolla de forma
modular y se versiona con Git y GitHub.

## Requisitos previos

- Python 3.8 o superior
- Git instalado y configurado

## Instrucciones básicas de uso

1. Clonar el repositorio:

   ```bash
   git clone <URL-DEL-REPOSITORIO>
   cd gestor-tareas-cli
   ```

2. Ejecutar la aplicación:

   ```bash
   python app.py
   ```

3. Elegir una opción del menú ingresando su número.
